PrismWave is a cross-platform music player built with **Avalonia 11 + Skia on .NET 10**, currently targeting Windows.
It features real local library management, online recommendations, an immersive full-screen lyrics stage, DSD playback support,
and a shared UI-agnostic core (`PrismWave.Core`) reused across UI frameworks.

## Branches

- [`main`](https://github.com/shanbei2033/PrismWave/tree/main) — **default development branch**, the Avalonia edition (rewritten from WinUI 3, sharing the same service layer)
- [`WinUI`](https://github.com/shanbei2033/PrismWave/tree/WinUI) — the legacy native WinUI 3 implementation, kept as a behavioral reference and for the v1.0.3 release below

## Features

- Local music library scan with folder management (TagLib# metadata, cover fallback)
- Online-first startup: the app opens directly to Home, with online mode
  enabled by default on first launch
- Online Home with a TOP100 trending banner, refreshed recommendations,
  new albums, hot songs, and unified online/local search
  - Schedules and recommendations generated by [prismwave-hits](https://github.com/shanbei2033/prismwave-hits)
- Library / Albums / Artists / Favorites views with drag-to-reorder and
  right-click context menus
- Bottom playback bar + immersive full-screen play page with a self-drawn
  lyrics stage (smooth scrolling, karaoke word-timing reveal, manual browse with auto-return)
- Lyrics: local, online auto-match, online search & cache, word-by-word,
  QQ QRC decode, NetEase YRC
- Playback queue with drag-to-reorder and on-demand online source recovery
- Playback modes: list loop, single repeat, shuffle
- Audio output modes: compatibility, WASAPI shared, WASAPI exclusive (libmpv)
- HITS radio mode: schedule-based online playback with 10 audio providers, cover & lyrics caching, prefetch
- Online songs can be added to library and favorites from search and Home
- Developer mode with live playback logs

## Stack

- Avalonia 11 + FluentAvalonia (UI)
- Skia (custom drawing: lyrics stage, rounded covers)
- C# / .NET 10
- CommunityToolkit.Mvvm
- PrismWave.Core — shared UI-agnostic service layer (audio, lyrics, online providers, persistence)
- libmpv with WASAPI shared/exclusive routing
- TagLib# local metadata reader

## Project layout

```text
PrismWave/
  src/PrismWave.Core/       Shared UI-agnostic services & view models
  src/PrismWave.Avalonia/   Avalonia UI application (main)
  src/PrismWave.WinUI/      Legacy WinUI 3 app (reference)
  tests/                    Regression tests (458, targeting Core)
  native/                   Native libraries (libmpv, BASS/DSD)
  tools/                    Build tools
```

## Run

```powershell
git checkout main
dotnet run --project src/PrismWave.Avalonia/PrismWave.Avalonia.csproj
```

## Build & Test

```powershell
git checkout main
dotnet build src/PrismWave.Avalonia/PrismWave.Avalonia.csproj
dotnet test tests/PrismWave.WinUI.Tests/PrismWave.WinUI.Tests.csproj
```

## Audio notes

Playback uses libmpv directly with WASAPI routing.

Available output modes on Windows:

- Compatibility
- WASAPI Shared
- WASAPI Exclusive
