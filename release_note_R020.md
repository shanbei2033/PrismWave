# PrismWave R020

## Release Note

PrismWave R020 focuses on playlist usability, desktop interaction polish, and a more complete lyrics workflow.

- Added a dedicated playback queue sidebar with a matching SVG queue button beside the playback-mode switch.
- Clicking a track outside the queue now rebuilds the current playlist with the selected track as item 1.
- Clicking a track inside the playback queue now switches within the existing queue without rebuilding it.
- Added drag reordering for Library, Favorites, and the active playback queue.
- Added remove-from-queue actions that only affect the current queue and do not delete source files.
- Added track deletion from the detail page, with a glass-style confirmation dialog and optional source-file plus same-name `.lrc` deletion.
- Refined queue interaction visuals: no visible drag-handle dots, hover-only remove button, and rounded drag proxies.
- Added middle-click autoscroll for major scrollable views, including an active cursor change and on-screen indicator.
- Improved online lyrics integration and QQ/QRC timed-lyrics compatibility groundwork.
